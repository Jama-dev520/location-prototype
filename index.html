Vendor Location List

Raw provider locations synced from PUDO Inc & LMS. Read-only except Sweeper (who physically picks up packages). Each vendor location generates one OC location ID (unless it is a suspected duplicate). QR dropoff marks LMS stores that accept QR-code drop-off (customer presents a QR code instead of a printed label).

OC Location List

OC-owned, downstream-facing locations, backfilled from vendor records. The enable switch lives here. When a vendor location goes inactive, its linked OC location is auto-disabled and blocked from downstream sync. QR dropoff is backfilled from the linked vendor location.

Sync Status

Daily incremental sync from each provider. New vendor locations auto-generate OC locations (default disabled).

Duplicate Review

Cross-provider address duplicates (fuzzy match ≥ 75%). A suspected duplicate does not generate an OC location until resolved.

Batch Disable✕

⚠ This changes downstream visibility for each location. An audit entry is written per location.
Cannot Enable✕
⚠ This OC location's linked vendor location is inactive. It is auto-disabled and blocked from downstream sync. It can be enabled again once the vendor location returns to active.
Version History✕
Semantic versioning — major = architecture change · minor = new feature · patch = fix or copy change. Every delivery is tagged and pushed.
Edit Store Details OC-level override✕
Only edit fields flagged as incorrect. Every change is recorded as STORE_DETAIL_EDIT against this OC location — the linked vendor record is never modified.
Changes become visible downstream after the next sync (PUDO Inc 02:00 · LMS 02:30).
Edit Opening Hours✕
One day can hold several ranges — e.g. a lunch break: 09:00–12:00 + 13:00–18:00. Leave a day empty to mark it closed.
Edit Sweeper✕
⚠ The new sweeper differs from the owner provider of this location.
